# IEEE article source

Compile `main.tex` with pdfLaTeX and BibTeX. Individual sections are in `sections/`,
the bibliography is `references.bib`, and all seven MATLAB figure PNGs are in
`figures/`. `IEEEtran.cls` is the exact class from the supplied Overleaf template.

The reviewed PDF is in `../report/plane_segmentation_report.pdf`. Local build
files belong in `build/` and are not committed. The complete article has 17 pages;
the course's page count is a guideline, not a fixed limit.

The first-page footnote and bibliography link to the public code repository:
https://github.com/Mattjing/plane-segmentation (organized version v1.1.0).
MATLAB code is submitted separately; full listings are not embedded in the paper.
